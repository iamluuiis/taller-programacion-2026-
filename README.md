# taller-programacion-2026-
## Project Description

This repository contains the semester project for the Programming Workshop 2026 course. The main objective of this project is to apply the knowledge learned during the semester, including object-oriented programming, software development, Git, GitHub, and modern development tools such as Visual Studio Code and GitHub Copilot.

The project is organized to follow good programming practices and maintain a clean and understandable structure. During its development, different concepts such as classes, objects, inheritance, encapsulation, polymorphism, composition, and SOLID principles will be applied. These concepts help create software that is easier to read, maintain, and improve over time.

This repository also serves as a way to practice version control using Git and GitHub. Every important change will be saved through commits, making it possible to keep track of the project's progress and collaborate with other developers if necessary.

The project is built using Java and Gradle. The repository includes a README file, a Java `.gitignore` file, and a basic Gradle configuration to support future development. As the course continues, new features and improvements will be added based on the class activities and assignments.

The goal of this project is not only to complete the course requirements but also to improve programming skills, problem-solving abilities, and teamwork. By the end of the semester, this repository will contain a complete software project that demonstrates the knowledge and experience gained throughout the course.
